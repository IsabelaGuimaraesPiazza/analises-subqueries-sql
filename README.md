# analises-subqueries-sql
Este repositório contém resolução de **três desafios práticos de SQL com subqueries** para resolver dores reais em três setores de mercado: **E-commerce, Educação e Logística**. 

O objetivo é demonstrar o conhecimento de **Subqueries (Consultas Aninhadas)** 

## Os Desafios 

### 1. E-commerce (Identificação de Produtos de Luxo)
*   **Contexto:** O time de marketing precisava listar apenas os produtos de alta gama da categoria 'Eletrônicos'.
*   **Regra:** Filtrar dinamicamente os produtos cujo preço individual seja estritamente **maior que a média de preço** de todos os produtos pertencentes apenas à categoria de 'Eletrônicos'.

### 2. EdTech (Mapeamento de Alunos Destaque)
*   **Contexto:** A coordenação pedagógica precisava isolar os alunos elegíveis para uma bolsa de estudos especial.
*   **Regra:** Filtrar os estudantes da disciplina 'Banco de Dados' que obtiveram nota final **acima da média aritmética** daquela turma específica.

### 3. Logística (Apoio Operacional à Frota)
*   **Contexto:** O gerente de frotas precisava identificar motoristas com baixa produtividade no mês para a aplicação de treinamentos de suporte.
*   **Regra:** Filtrar os entregadores cujo total de viagens mensais tenha sido **menor que a média geral** de entregas de toda a frota da empresa.
